როგორ გავაკეთოთ მარტივი HTML საიტი საკუთარი ხელით

Elena · 2026-11-18

პატარა გვერდი შეიძლება ხელით დაიწეროს ტექსტურ რედაქტორში. ქვემოთ სრული მაგალითია: ერთი HTML ფაილი ჩაშენებული სტილებით. საკუთარ კომპიუტერზე მუშაობა უფასოა; დომენი და ინტერნეტში განთავსება ცალკე საკითხია.

1. შექმენით საქაღალდე და უბრალო ტექსტური ფაილი

დაარქვით საქაღალდეს „my-site“. გახსენით მარტივი ტექსტური რედაქტორი. macOS-ზე TextEdit-ში აირჩიეთ „უბრალო ტექსტის“ რეჟიმი ფორმატირებული დოკუმენტის ნაცვლად; Windows-ზე გამოდგება Notepad. დოკუმენტების ტექსტური პროცესორი არ გამოდგება.

2. დააკოპირეთ სრული კოდი

ეს სასწავლო სახელოსნოა გამოგონილი შინაარსით. მაგალითში არ არის სკრიპტები, გარე ბიბლიოთეკები, მთვლელები, ფორმა და რეალური კონტაქტები. მისი შესწავლა და ხელით შეცვლა შეიძლება.

<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Workshop - furniture repair</title>
<meta name="description" content="Sample page of a workshop: services, how we work and contacts.">
<style>
* { box-sizing: border-box; }
body { margin: 0; font: 18px/1.6 system-ui, sans-serif; color: #193537; background: #f3f7f5; }
header, main, footer { width: min(100% - 32px, 880px); margin-inline: auto; }
header, footer { padding-block: 24px; }
nav { display: flex; gap: 16px; flex-wrap: wrap; }
a { color: #176063; text-underline-offset: 3px; }
h1 { font-size: clamp(30px, 6vw, 50px); line-height: 1.15; }
section { padding: 24px; margin-block: 20px; background: white; border-radius: 12px; }
.button { display: inline-block; padding: 12px 18px; border-radius: 8px; background: #176063; color: white; }
@media (max-width: 480px) { section { padding: 18px; } }
</style>
</head>
<body>
<header>
<strong>Workshop</strong>
<nav aria-label="Page menu"><a href="#services">Services</a><a href="#steps">How we work</a><a href="#contacts">Contacts</a></nav>
</header>
<main>
<section>
<h1>Furniture repair: tell us about your task</h1>
<p>This is a sample. Replace the name, city and description with details of your business.</p>
<a class="button" href="#contacts">Contact the workshop</a>
</section>
<section id="services"><h2>Services</h2><ul><li>Chair repair</li><li>Upholstery replacement</li><li>Restoration of parts</li></ul></section>
<section id="steps"><h2>How we work</h2><ol><li>You describe the task.</li><li>We agree on scope, price and deadline.</li><li>You check the finished work.</li></ol></section>
<section id="contacts"><h2>Contacts</h2><p>Put your real phone number and email here.</p></section>
</main>
<footer>Sample layout. Add your own name and up-to-date details.</footer>
</body>
</html>

3. შეინახეთ როგორც index.html UTF-8 კოდირებით

შენახვისას აირჩიეთ UTF-8 კოდირება და სახელი index.html. თუ რედაქტორი ფაილის ტიპს გთავაზობთ, აირჩიეთ „ყველა ფაილი“ ან HTML. დარწმუნდით, რომ სახელი არ გამოვიდა index.html.txt: ჩართეთ ფაილის გაფართოებების ჩვენება, თუ დამალულია.

4. გახსენით გვერდი ბრაუზერში

ორჯერ დააწკაპუნეთ ფაილზე ან გადაიტანეთ ბრაუზერის ფანჯარაში. უნდა გამოჩნდეს სათაური, სამი ბლოკი და მენიუს ბმულები. თუ თავად კოდს ხედავთ, შეამოწმეთ გაფართოება და ფაილი ბრაუზერით გახსენით. თუ ასოები დამახინჯებულია, შეამოწმეთ UTF-8 შენახვისას და meta charset ხაზი.

5. შეცვალეთ შინაარსი და შეამოწმეთ ტელეფონზე

შეცვალეთ ტექსტი თეგებს შორის, თავად თეგები დატოვეთ. მენიუ ბლოკებზე მიდის მათი id-ით: ბმული #contacts კონტაქტების ბლოკს ხსნის. ფაილის შეცვლის შემდეგ შეინახეთ და განაახლეთ გვერდი ბრაუზერში.

შეავიწროვეთ ფანჯარა. meta name="viewport" ხაზი და მოქნილი სიგანე გვერდს ვიწრო ეკრანზე ეტევა; media-მოთხოვნა შიდა დაშორებებს ამცირებს. გამოქვეყნებამდე შეამოწმეთ რეალურ ტელეფონზე. საკუთარი კონტაქტების დამატებისას შეგიძლიათ ჩასვათ tel: ან mailto: ბმული; ელფოსტის ბმული ფოსტის პროგრამას ხსნის და სერვერით განაცხადის გაგზავნას არ ანაცვლებს.

რა შეუძლია ამ საიტს და რა აკლია

ის აჩვენებს შინაარსს და გადაადგილებს განყოფილებებს შორის. ის არ ინახავს განაცხადებს, არ ქმნის შეკვეთებს, არ იღებს გადახდას და არ გაძლევთ რედაქტირების კაბინეტს. ასეთი ფუნქციები ცალკე დამუშავებას მოითხოვს. ფაილის გამოქვეყნება თავისთავად ვიზიტორებს არ მოიყვანს და ძიებაში პოზიციებს არ გარანტირებს.

HTML-ისა და CSS-ის საფუძვლების შესასწავლად შეგიძლიათ გამოიყენოთ MDN-ის შესავალი HTML-ში. ფაილის საკუთარ კომპიუტერზე გახსნა უფასოა, მაგრამ საჯარო განთავსება არჩეული ჰოსტინგისა და დომენის პირობებზეა დამოკიდებული.

კოდი და ინსტრუქცია უფასოა. თუ გჭირდებათ საიტი თქვენი ბიზნესისთვის, ადაპტაცია ან მაგალითზე მეტი ფუნქცია, მიწერეთ ელენას: მოცულობა და ფასი სამუშაოს დაწყებამდე შეთანხმდება.
