How to make a simple HTML website yourself

Elena · 2026-11-18

A small page can be written by hand in a text editor. Below is a complete example: one HTML file with built-in styles. Working on your own computer is free; the domain and publishing online are a separate matter.

1. Create a folder and a plain text file

Name the folder “my-site”. Open a plain text editor. On macOS choose “plain text” mode in TextEdit instead of a formatted document; on Windows Notepad will do. A word processor is not suitable.

2. Copy the complete code

This is a sample workshop with fictional content. The example has no scripts, external libraries, counters, forms or real contacts. You can study it and edit it by hand.

<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Workshop - furniture repair</title>
<meta name="description" content="Sample page of a workshop: services, how we work and contacts.">
<style>
* { box-sizing: border-box; }
body { margin: 0; font: 18px/1.6 system-ui, sans-serif; color: #193537; background: #f3f7f5; }
header, main, footer { width: min(100% - 32px, 880px); margin-inline: auto; }
header, footer { padding-block: 24px; }
nav { display: flex; gap: 16px; flex-wrap: wrap; }
a { color: #176063; text-underline-offset: 3px; }
h1 { font-size: clamp(30px, 6vw, 50px); line-height: 1.15; }
section { padding: 24px; margin-block: 20px; background: white; border-radius: 12px; }
.button { display: inline-block; padding: 12px 18px; border-radius: 8px; background: #176063; color: white; }
@media (max-width: 480px) { section { padding: 18px; } }
</style>
</head>
<body>
<header>
<strong>Workshop</strong>
<nav aria-label="Page menu"><a href="#services">Services</a><a href="#steps">How we work</a><a href="#contacts">Contacts</a></nav>
</header>
<main>
<section>
<h1>Furniture repair: tell us about your task</h1>
<p>This is a sample. Replace the name, city and description with details of your business.</p>
<a class="button" href="#contacts">Contact the workshop</a>
</section>
<section id="services"><h2>Services</h2><ul><li>Chair repair</li><li>Upholstery replacement</li><li>Restoration of parts</li></ul></section>
<section id="steps"><h2>How we work</h2><ol><li>You describe the task.</li><li>We agree on scope, price and deadline.</li><li>You check the finished work.</li></ol></section>
<section id="contacts"><h2>Contacts</h2><p>Put your real phone number and email here.</p></section>
</main>
<footer>Sample layout. Add your own name and up-to-date details.</footer>
</body>
</html>

3. Save it as index.html in UTF-8

When saving, choose UTF-8 encoding and the name index.html. If the editor offers a file type, choose “all files” or HTML. Make sure the name did not become index.html.txt: turn on file extensions if they are hidden.

4. Open the page in a browser

Double-click the file or drag it into a browser window. You should see a heading, three blocks and menu links. If you see the code itself, check the extension and open the file with a browser. If letters look corrupted, check UTF-8 when saving and the meta charset line.

5. Change the content and check on a phone

Replace the text between tags, keeping the tags themselves. The menu leads to blocks by their id: the link #contacts opens the contacts block. After changing the file, save it and refresh the page in the browser.

Make the window narrower. The meta name="viewport" line and flexible widths help the page fit a narrow screen; the media query reduces padding. Check on a real phone before publishing. When you add your contacts, you can insert a tel: or mailto: link; an email link opens the mail program and does not replace sending a request through a server.

What this site can do and what it lacks

It shows content and moves between sections. It does not store requests, create orders, accept payment or offer an editing dashboard. Such features need separate development. Publishing a file does not by itself bring visitors or guarantee search positions.

You can learn the basics of HTML and CSS from MDN's introduction to HTML. Opening the file on your computer is free, but public hosting depends on the terms of the chosen hosting and domain.
