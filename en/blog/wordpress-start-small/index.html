How to save on a website: a WordPress home page you edit yourself

Elena · 2026-11-18

If you are ready to fill the site yourself, you can start with a small agreed structure and a WordPress home page. The developer sets up the foundation and shows the necessary operations, and you change texts and images within the prepared solution.

What to order at the first stage

Describe the content of the home page, the menu and the visitor's action. Ask for a suitable theme, agreed blocks, a mobile version and a way to get in touch. List in advance what you will change yourself: text, a photo, a contact or new pages.

This is an individual scope of work, not a promise that the whole development of a store or company site is included in the price of one page. If the menu needs separate sections, decide who creates them and when. Empty “for the future” links are not needed.

The home page should be editable from the start

It is better to build it right away in the chosen theme and editor. In the WordPress block editor content is organised in blocks, but the available operations depend on the theme and setup.

Another way is to adapt a ready HTML layout into a WordPress theme. This is separate work: simply uploading an HTML file does not turn all its elements into convenient editor fields. So the wish “to change everything myself later” should be stated before ordering.

Where you can save

Start with the home page and the sections you really need, without “just in case” features. Prepare your own facts, texts and images using a checklist. Choose a suitable ready-made theme instead of many custom elements. After handover and training, add content yourself.

Savings are not guaranteed: an unsuitable theme and rework can increase the scope. Before buying, ask for a comparison of scope between a ready-made theme and a custom design.

Which costs remain

Domain, hosting, setup and support do not become free because you edit the site yourself. A theme or plugins may be paid; check licences and renewals before choosing. A form, a store, payment and integrations are separate features. If you need to sell, first work out the path from catalogue to order.

What to check at handover

1) Replace a heading, a photo and a contact yourself on a test page. 2) Look at the result on a phone: the text is readable, buttons are reachable, blocks do not run off the screen. 3) Create a draft of a new page and check the menu if this operation is part of the task. 4) Get instructions for the agreed actions and the backup procedure. 5) Decide who is responsible for updates of the system and plugins, and what counts as separate additional work.

Replacing materials yourself does not mean any logic of the site can be changed with one click. Custom fields, integrations or a new structure may require a developer.

If you want to start with the home page, write to Elena about what should be on it and which changes you want to make yourself. Price and timeline are set after discussion, paid components separately by agreement.
