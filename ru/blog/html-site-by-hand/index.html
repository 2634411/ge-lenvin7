Как сделать простой сайт на HTML своими руками

Elena · 2026-11-18

Небольшую страницу можно написать в текстовом редакторе вручную. Ниже полный пример: один файл HTML со встроенными стилями. Работа на своём компьютере бесплатна; домен и размещение в интернете — отдельный вопрос.

1. Создайте папку и обычный текстовый файл

Назовите папку «my-site». Откройте редактор простого текста. На macOS в TextEdit выберите режим «обычный текст» вместо форматированного документа; в Windows подойдёт Блокнот. Текстовый процессор для документов не подходит.

2. Скопируйте полный код

Это учебная мастерская с вымышленным содержанием. В примере нет скриптов, внешних библиотек, счётчиков, формы и реальных контактов. Его можно изучать и менять вручную.

<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Workshop - furniture repair</title>
<meta name="description" content="Sample page of a workshop: services, how we work and contacts.">
<style>
* { box-sizing: border-box; }
body { margin: 0; font: 18px/1.6 system-ui, sans-serif; color: #193537; background: #f3f7f5; }
header, main, footer { width: min(100% - 32px, 880px); margin-inline: auto; }
header, footer { padding-block: 24px; }
nav { display: flex; gap: 16px; flex-wrap: wrap; }
a { color: #176063; text-underline-offset: 3px; }
h1 { font-size: clamp(30px, 6vw, 50px); line-height: 1.15; }
section { padding: 24px; margin-block: 20px; background: white; border-radius: 12px; }
.button { display: inline-block; padding: 12px 18px; border-radius: 8px; background: #176063; color: white; }
@media (max-width: 480px) { section { padding: 18px; } }
</style>
</head>
<body>
<header>
<strong>Workshop</strong>
<nav aria-label="Page menu"><a href="#services">Services</a><a href="#steps">How we work</a><a href="#contacts">Contacts</a></nav>
</header>
<main>
<section>
<h1>Furniture repair: tell us about your task</h1>
<p>This is a sample. Replace the name, city and description with details of your business.</p>
<a class="button" href="#contacts">Contact the workshop</a>
</section>
<section id="services"><h2>Services</h2><ul><li>Chair repair</li><li>Upholstery replacement</li><li>Restoration of parts</li></ul></section>
<section id="steps"><h2>How we work</h2><ol><li>You describe the task.</li><li>We agree on scope, price and deadline.</li><li>You check the finished work.</li></ol></section>
<section id="contacts"><h2>Contacts</h2><p>Put your real phone number and email here.</p></section>
</main>
<footer>Sample layout. Add your own name and up-to-date details.</footer>
</body>
</html>

3. Сохраните как index.html в UTF-8

При сохранении выберите кодировку UTF-8 и имя index.html. Если редактор предлагает тип файла, выберите «все файлы» или HTML. Убедитесь, что имя не получилось index.html.txt: включите показ расширений файлов, если они скрыты.

4. Откройте страницу в браузере

Дважды нажмите на файл или перетащите его в окно браузера. Должны появиться заголовок, три блока и ссылки меню. Если вы видите сам код, проверьте расширение и откройте файл именно браузером. Если буквы искажены, проверьте UTF-8 при сохранении и строку meta charset.

5. Измените содержание и проверьте телефон

Заменяйте текст между тегами, сохраняя сами теги. Меню ведёт к блокам по их id: ссылка #contacts открывает блок контактов. Изменили файл — сохраните и обновите страницу в браузере.

Уменьшите ширину окна. Строка meta name="viewport" и гибкая ширина помогают странице помещаться на узком экране; media-запрос уменьшает отступы. Перед публикацией проверьте на настоящем телефоне. Когда добавите свои контакты, можно вставить ссылку вида tel: или mailto:; ссылка на email открывает почтовую программу и не заменяет отправку заявки через сервер.

Что этот сайт умеет и чего ему не хватает

Он показывает содержание и перемещает по разделам. Он не хранит заявки, не создаёт заказы, не принимает оплату и не даёт кабинет редактирования. Такие функции требуют отдельной разработки. Публикация файла сама по себе не приводит посетителей и не гарантирует позиции в поиске.

Основы HTML и CSS можно изучать по введению MDN в HTML. Открытие файла у себя бесплатно, но публичное размещение зависит от условий выбранного хостинга и домена.
